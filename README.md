## 📌 Project Overview

**SafePay** is a web-based AI-powered fraud detection platform designed to analyze online payment transactions and identify potential risks before they are completed.

The system provides users with transaction risk evaluation, fraud awareness insights, and a visual dashboard to monitor suspicious activities. SafePay aims to enhance digital payment security using intelligent decision-making logic.

---

## 🎯 Objective

The main goals of SafePay are:

- Detect fraudulent online payment transactions
- Provide risk scoring before payment confirmation
- Improve awareness of digital payment fraud
- Enhance financial security using AI concepts

## ⚙️ How It Works

1. User enters transaction details.
2. The system processes the input using fraud detection logic.
3. A risk score is generated.
4. The dashboard displays transaction status and insights.
5. The user can take preventive action if risk is high.
